# gestion_libros_electronicos
Sistema de gestión de libros electrónicos desarrollado en programación Go

FUNCIONALIDADES PRINCIPALES

Registro e inicio de sesión de usuarios.
Gestión de libros electrónicos (CRUD).
Gestión de autores y categorías.
Búsqueda de libros por título, autor y categoría.
Descarga de archivos digitales (PDF/EPUB).

ESTRUCTURA DEL PROYECTO

models/ – Entidades del sistema.
controllers/ – Lógica de control.
database/ – Conexión y acceso a datos.
utils/ – Funciones auxiliares.
config/ – Configuración de la aplicación.

EJECUTAR EL PROYECTO

go mod tidy
go run .
